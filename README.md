# TeffaCoreAPI

TeffaCoreAPI là core plugin/API dùng cho hệ sinh thái Teffa trên server Minecraft Paper.

## Features

- Player profile system
- Permission service
- Diagnostic service
- Client bridge/session system
- Join/leave listener
- Teffa command base

## Requirements

- Paper 26.1.2
- Java 25
- Maven

## Build

```bash
mvn clean package
